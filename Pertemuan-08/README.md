### Tentang Web
Web ini jualan jam tangan perempuan namanya Watch Aqila. Lokasinya di Pangkalpinang, di Jl. Bukit Merapin. menjual aneka jam tangan perempuan dengan berbagai desain dan harga yang terjangkau
di Kota Pangkalpinang.

### File yang ada di folder Pertemuan-08
- index.html : file utama buat nampilin web, ada home, profil, buku tamu
- index.php : sama kayak index.html tapi ada php nya buat alert kalau buku tamu di isi
- style.css : buat warna, saya pakai warna ungu #C7A0D3 sama pink #EAD3F0 biar kayak di foto proyektor
- script.js : buat cek form buku tamu biar gak kosong, kalau kosong keluar alert wajib diisi
- jam1.jpeg, jam2.jpeg, jam3.jpeg : foto produk jam
- foto.jpg : foto profil (kalau ada)

### Permasalahan yang saya alami pas bikin
1. index.html css nya gak kepanggil, ternyata nama file saya tulis Style.css huruf besar, harusnya style.css kecil semua jadi gak kebaca.
2. Gambar jam gak muncul karena file masih di download belum dipindah ke folder Pertemuan-08.
3. Form buku tamu awalnya saya tulis <from> bukan <form> jadi gak jalan, terus id nya contacfrom salah ketik harusnya contactForm.
4. Di script.js saya panggil getElementById("hp") padahal di html id nya "nohp" jadi gak nyambung.
5. index.php kalau dibuka langsung klik 2x malah keluar kode php nya, harus lewat XAMPP localhost baru jalan.

### Cara jalanin web nya
1. Taruh folder Pertemuan-08 di dalam htdocs XAMPP
2. Hidupin Apache di XAMPP
3. Buka chrome ketik localhost/Pertemuan-08/index.html
4. Kalau mau yang php ketik localhost/Pertemuan-08/index.php
5. Coba isi buku tamu, kalau kosong nanti ada tulisan alert harus wajib diisi
