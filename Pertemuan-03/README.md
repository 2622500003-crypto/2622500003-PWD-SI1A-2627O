## Pengujian GET dan POST 

- Hasil pengujian GET: [Dengan `method="get"`, setelah submit query string tampil di URL. GET menempatkan pasangan `name=value` di URL dan data terlihat langsung.] 
- Contoh URL encoding yang ditemukan: [https://2622500003-crypto.github.io/2622500003-PWD-SI1A-2627O/Pertemuan-03/index.html?nama=saqila+bahari+rizky&email=2622500003%40mahasiswa.atmaluhur.ac.id&semester=1&tanggal=2026-08-10&jenis_pesan=saran&minat=HTML&prodi=SI&pesan=terimakasi] 
- Hasil pengujian POST:
[- Mengubah form menjadi `<form action="index.html" method="post">` lalu submit di GitHub Pages.
- Hasil: Parameter tidak tampil di URL karena dikirim via body request.
- GitHub Pages merespons `405 Not Allowed` karena tidak ada pemrosesan sisi peladen. Ini sesuai catatan modul H.4 bahwa POST baru bermakna saat ada PHP.
- Setelah uji, dikembalikan ke `method="get"` agar artefak utama P3 tetap bisa diamati URL encoding-nya.]
